# NotchApp

🇷🇺 Русский · [🇬🇧 English](README.en.md)

Утилита для macOS, которая живёт в вырезе (notch) MacBook. Наводишь курсор на вырез, и он раскрывается в панель. Свёрнутая, она почти не заметна и показывает эквалайзер, когда играет музыка.

## Возможности

### Музыка

Название, обложка, перемотка и управление для любого плеера, в том числе Яндекс Музыки. Эквалайзер у выреза двигается в такт звуку.

<p align="center"><img src="docs/demo-music.gif" width="640" alt="Музыка"></p>

### Claude

Отслеживание сессий Claude Code и чатов в приложении Claude:

- статусы работы, число действий, таймер и заполнение контекста;
- запросы разрешений и вопросы с кнопками можно закрывать прямо из выреза;
- прогресс плана (например, 2 из 5);
- панель выезжает вниз и мягко подсвечивается, когда агенту нужен ответ.

<p align="center"><img src="docs/demo-claude.gif" width="640" alt="Claude"></p>

### Файлы, буфер обмена и переводчик

- **Файлы.** Скриншоты и временная полка: перетаскиваешь файлы в панель, потом забираешь оттуда.
- **Буфер обмена.** История скопированного.
- **Переводчик RU ↔ EN.** Работает на системном переводе macOS. Идентификаторы в `camelCase` и `snake_case` разбиваются на слова перед переводом.

## Требования

- macOS 15 или новее, MacBook с вырезом (на остальных тоже запустится, но выглядит иначе)
- Xcode и [xcodegen](https://github.com/yonaskolb/XcodeGen): `brew install xcodegen`
- Apple ID, в который выполнен вход в Xcode. Стабильная подпись нужна, чтобы macOS не сбрасывала выданные разрешения после каждой пересборки.

## Установка

```bash
git clone https://github.com/burr1t0/NotchApp.git
cd NotchApp
scripts/install.sh
```

Скрипт соберёт приложение, поставит его в `/Applications` и запустит. Опции: `--debug` для отладочной сборки, `--no-launch`, чтобы не запускать после установки.

В `project.yml` указан `DEVELOPMENT_TEAM` автора. Замени его на свой Team ID, иначе сборка не подпишется.

## Подключение Claude

Откройте вкладку Claude в панели. Приложение само предложит подключение:

- **Claude Code.** Добавляет хуки и строку состояния в `~/.claude/settings.json`. Чужие настройки не затираются, а если слот строки состояния уже занят, он остаётся как есть. Отключить можно кнопкой «Отключить» в том же окне.
- **Чаты в приложении Claude.** Кнопка «+ Чаты» регистрирует локальный MCP-сервер `notch-mcp.py` в `claude_desktop_config.json` (перед правкой делается резервная копия). Редактируйте конфиг только при закрытом приложении Claude, иначе оно перезапишет файл. Дополнительно можно загрузить в Claude скилл из `skills/notch-status`, тогда чаты чаще сами сообщают статус.

Все служебные файлы лежат в `~/.notchapp/`. Приложение ничего не отправляет в сеть: события идут через локальный Unix-сокет.

### Ограничения

- Лимиты тарифа (5 часов и неделя) доступны только в терминальном Claude Code. Приложение Claude их не отдаёт.
- Использовать инструменты `notch_status` и `notch_confirm` в обычных чатах модель решает сама. Если статус не появился, попросите об этом прямо в запросе.

## Разрешения

- **Запись звука.** Нужна, чтобы эквалайзер реагировал на громкость. Звук не записывается и никуда не передаётся.
- **Универсальный доступ (Accessibility).** Нужен только для отправки текста в чат Claude из панели.
